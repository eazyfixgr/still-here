How this game makes a scenario

A synthetic Gompertz survival curve is fitted to the two population averages for each sex. It gives an age-aware game baseline. Values at other ages are simulated, not official life-table values. This curve has not been validated for individual health assessment.

Fictional habit points: smoking 0 / −2 / −5 / −8; alcohol 0 / −1 / −3 / −6; diet −2 / 0 / +2 / +3; activity −2 / 0 / +2 / +4; sleep −2 / 0 / +1. The remaining game time is multiplied by exp(total points / 45). Points are not real years of life.

The endpoint is fixed when you start. A year in the model is 365.2425 days. The display splits the remaining interval into calendar years and months, then days, hours, minutes and seconds. Achievements use actual elapsed time. If you pass the endpoint, Overtime counts upward.
